Decoy Watcher

Watches small decoy addresses on Zcash testnet. If one is spent when you did not spend it, the alarm fires.

Reads public data only. Never paste a key or recovery words here.

Setup

Insight explorers list transparent addresses only, so this live check uses transparent testnet decoys. Shielded decoys would need viewing-key scanning, which is not built. If the explorer is down or blocks browser requests, the address shows "unknown": that is neither an alarm nor "safe".
